# Previews de templates de currículo (`resume/`)

Cada subpasta **deve** ter o mesmo nome que o `template_key` da API (ex.: `resume_classic`).

## Conteúdo esperado por `<template_key>/`

- `preview-desktop.webp` — hero do catálogo (desktop).
- `preview-mobile.webp` — carrossel / vista mobile.
- `thumb.png` — opcional.
- `notes.md` — opcional (ATS, tipografia, margens).

## Fila de importação

Ficheiros ainda sem `template_key` conhecido: [`_mapeamento-pendente/`](_mapeamento-pendente/) (ver `MAPEAMENTO.md`).
