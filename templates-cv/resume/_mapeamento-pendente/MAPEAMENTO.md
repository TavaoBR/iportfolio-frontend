# Mapeamento pendente — previews para `template_key`

Os ficheiros nesta pasta foram importados com nomes genéricos (`original-<hash>.webp`). Quando souber o **`template_key`** exato devolvido por `GET /api/templates`, mova cada ficheiro para:

`templates-cv/resume/<template_key>/preview-desktop.webp`  
`templates-cv/resume/<template_key>/preview-mobile.webp`

Se um único ficheiro servir só para desktop, pode duplicá-lo como `preview-mobile.webp` temporariamente ou gerar um crop mobile real.
